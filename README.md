# Barangay Health Record Tracker

## Problem Statement

Barangay Health Workers (BHWs) in Barangay Kitabog, Titay, Zamboanga Sibugay, experience difficulties organizing, managing, and finding patient records because they rely on manual record-keeping.

This makes it difficult and time-consuming to search for patient information and maintain organized health records.

## Proposed Solution

The Barangay Health Record Tracker is a web-based system designed to help Barangay Health Workers register patients, record consultations, and search existing patient records.

## Main Feature

- Patient registration
- Recording patient consultations
- Searching patient records
